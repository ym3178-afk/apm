PROJECT EXPERIENCE

Xiuliu

AI Research Paper Reading Agent for Students and Researchers
Aug–Sep 2026
Product Prototype ↗
01

Product Discovery & Definition

Identified three core pain points in academic paper reading—high effort to assess value, complex reading paths tied to research goals, and difficulty verifying AI-generated conclusions. Defined AI Overview, AI Deep Reading, and AI Assistant modules and independently built an interactive web prototype. Set product boundaries around trustworthy single-paper reading, no unsupported inference, and no replacement of academic judgment.

02

AI System Architecture

Established “LLMs for understanding, deterministic systems for rules.” Used the LLM layer for intent understanding, task planning, reasoning, and response generation, while deterministic components handle document parsing, structured retrieval, source anchoring, and verification. Replaced generic RAG with single-document structure-aware RAG and constrained planning through task-to-section routing templates.

03

AI Interaction & Trust Mechanisms

Designed a seven-stage workflow—Intent Understanding → Slot Extraction → Path Planning → Retrieval → Evidence Extraction → Reasoning → Verification. Added minimal-source tool routing across selected text, current paper, conversation history, and web search. Required claims to be grounded in page numbers, sections, and source text, with an independent “no evidence, no output” verification layer.

04

Evaluation & Data Experiments

Built a fixed 24-case evaluation set across Overview, Deep Reading, and Assistant tasks, with each case repeated three times per version. Ran V1 Baseline → V2 Structured → V3 Optimized controlled experiments using content accuracy, evidence grounding, source-location accuracy, tool-routing accuracy, citation accuracy, hallucination rate, and task-completion rate as release gates. Verification-layer injection tests targeted ≥90% detection and ≤5% false positives.

05

Results & Iteration Loop

Improved Overview 78.2→94.7 while severe hallucinations fell 7.5%→0.8%; Deep Reading 76.8→94.4; Assistant 74.1→95.1; tool-routing accuracy 64%→97%; three-run consistency 81%→97%. Established a P0 blocking mechanism, 10-layer bad-case taxonomy, and Root Cause → Fix → Re-run → Regression Test loop.

02 / 案例研究
项目经历

Xiuliu

面向学生与科研人员的 AI 论文精读 Agent
2026.08–2026.09
产品原型 ↗
01

产品洞察与定义

识别论文阅读中的三类核心痛点——判断论文价值成本高、与科研目标相关的阅读路径复杂，以及 AI 生成结论难以验证。定义 AI Overview、AI Deep Reading 和 AI Assistant 模块，并独立搭建交互式 Web 原型。将产品边界设定为可信的单篇论文阅读：不做无依据推断，不替代学术判断。

02

AI 系统架构

建立“LLM 用于理解，确定性系统用于规则”的架构。LLM 层负责意图理解、任务规划、推理与回复生成；确定性组件负责文档解析、结构化检索、来源锚定和验证。以单文档结构感知 RAG 替代通用 RAG，并通过 task-to-section routing templates 约束规划。

03

AI 交互与可信机制

设计七阶段工作流——意图理解 → 槽位抽取 → 路径规划 → 检索 → 证据抽取 → 推理 → 验证。在选中文本、当前论文、对话历史与联网搜索之间加入最小必要信息源的工具路由。要求结论必须由页码、章节和原文依据支撑，并设置独立的“无证据，不输出”验证层。

01意图理解 → 02槽位抽取 → 03路径规划 → 04检索 → 05证据抽取 → 06推理 → 07验证
04

评测与数据实验

围绕 Overview、Deep Reading 和 Assistant 任务构建固定 24 条评测用例，每个版本中每条用例重复 3 次。开展 V1 Baseline → V2 Structured → V3 Optimized 对照实验，并将内容准确率、证据支撑率、来源定位准确率、工具路由准确率、引用准确率、幻觉率和任务完成率作为上线门禁。验证层注入测试目标为检出率 ≥90%、误报率 ≤5%。

05

结果与迭代闭环

Overview 从 78.2 提升至 94.7，同时严重幻觉从 7.5% 降至 0.8%；Deep Reading 从 76.8 提升至 94.4；Assistant 从 74.1 提升至 95.1；工具路由准确率从 64% 提升至 97%；三次运行一致率从 81% 提升至 97%。建立 P0 阻断机制、10 层 Bad Case 分类体系，以及 Root Cause → Fix → Re-run → Regression Test 迭代闭环。
